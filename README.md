# daily-sales-log

A daily sales log for tracking your sales, day by day.

Every day gets its own card — see at a glance how much you made,
then click in to add sales and watch the total update as you go.
Simple, focused, and built for the way you actually work.

## Features
- One card per day, with the day's total up front
- Add sales with a description and amount
- Live running total per day
- Newest days first

## Tech
Plain HTML, CSS, and JavaScript. No build step, no dependencies.
